SmartPlus Wear is a modified Akuvox SmartPlus phone application with a paired
Wear OS unlock button.

The phone application retains SmartPlus's normal login and building setup. Mark
a compatible remote-unlock door as a favorite, then press Unlock on the watch.
The watch sends an app-private Wear Data Layer message to the paired phone, and
the phone asks SmartPlus's existing authenticated request layer to open the
door. The watch does not need its own Wi-Fi or cellular connection.

Add the SmartPlus Unlock tile to the Wear OS carousel, or the SmartPlus Unlock
complication to a watch face slot, for one-tap access without opening the app.

The rebuilt phone app also drops SmartPlus's portrait lock and window-size
limits, so it fills the screen on foldables and tablets instead of running
letterboxed at phone size.

This repository contains build and injection tooling, not Akuvox's proprietary
application. Release APKs are produced locally from a user-supplied SmartPlus
APK and contain proprietary Akuvox code. An authorized SmartPlus account and
Akuvox's proprietary cloud service are required.

Use this application only with a building and account you are authorized to
access. The separately installable Wear OS APK is available from GitHub
Releases.
